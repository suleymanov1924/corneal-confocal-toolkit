# Public Release Checklist

Author attribution: `Art.Suleimanov1924`

Use this checklist before publishing the project to GitHub.

## Safe to publish

- source code in `confocaltoolkit/`
- helper scripts in `scripts/`
- neutral documentation
- synthetic or fully de-identified examples

## Do not publish

- `HEYEX/` archives
- patient images or screenshots
- report exports from real cases
- spreadsheets with names, IDs, dates of birth, or visit dates

## Recommended workflow

1. Create a new empty GitHub repository.
2. Upload only the contents of this `public_repo_confocal_toolkit` folder.
3. Review the first commit manually before pushing.
4. Add a license file if you want the code to be reusable by others.
5. Add a short disclaimer that the tool is for research use only.

## Suggested repo subtitle

Open research toolkit for automated analysis of corneal confocal microscopy data from Heidelberg HRT-III / Rostock Cornea Module.
